  Issue:      15 rapid login attempts did not trigger 429.
  Impact:     Brute force attacks possible.
  Fix:        Verify express-rate-limit middleware is correctly mounted.
              Check if ipKeyGenerator produces consistent keys.
              Test with actual browser client.

FINDING 2: Invalid JSON Returns 500 (P1)
  Endpoint:   POST /api/v1/* (any POST endpoint)
  Issue:      Malformed JSON body causes HTTP 500 instead of 400.
  Impact:     Server errors exposed to client; potential information leakage.
  Fix:        Add express.json error handler:
              app.use(express.json({
                verify: (req, res, buf) => { req.rawBody = buf; }
              }));
              Or wrap with try/catch returning 400.

FINDING 3: JWT Statelessness Trade-off (P2 - Informational)
  Issue:      Logout clears cookie but JWT remains valid until expiry.
  Impact:     Stolen tokens usable until expiry even after user logs out.
  Mitigation: Implement token blacklist (Redis) or use short-lived tokens
              with refresh token rotation.
